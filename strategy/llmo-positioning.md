# 金井酒造店 LLMO/AIO ポジション定義書（v1 ドラフト）

作成日: 2026-06-22 / 対象: ChatGPT・Claude・Gemini・Perplexity・AI Overview、および将来のエージェンティックコマース

---

## 0. 前提とタイミング
- **エージェンティックコマース主流化 = 来年〜再来年（〜2027頃）** と想定。
- この**1〜2年の猶予は「複利資産を積む期間」**。効く信号（学習データ反映／外部被引用／レビュー／構造化／必要なら商品開発）はすべて時間をかけて積み上がる。
- **原則：属性で“入り”、一行で“勝つ”。**
  - 絞り込み属性（度数・味・価格・容量・ギフト可否・ペアリング）でエージェントの候補セットに入る。
  - 一行の検証可能な差別化で tiebreak に勝ち、推薦理由として引用される。

---

## 1. 背骨（ブランドの一行 = tiebreak 差別化）
> **「名水百選＋“水道水日本一”の水で醸す、やわらかく綺麗な酒」**

- 全国通用・流行に左右されない（evergreen）・味（やわらかさ／clean）の理由まで説明できる。
- 検証フック（**要・出典確定**）:
  - 秦野盆地湧水群 = 環境省「名水百選」選定（1985年）※要再確認
  - 秦野の水道水 = ほぼ100%地下水・利き水大会で高評価／日本一 ※正確な大会名・年・出典を確定させる
- ⚠️ LLMOでは**固有名詞・年・出典が揃った主張のみ引用される**。曖昧な「日本一」は弱い。最優先で裏取りする。

## 2. 狙うポジション（answer-slot 群）

### Position 1：名水の酒蔵（背骨・全国・evergreen）
- 狙うクエリ：`名水 日本酒` / `軟水 日本酒 すっきり` / `水がうまい 酒蔵` / `きれいな 日本酒`
- 武器：水ストーリー ＋ やわらか・clean 系商品
- 主力商品：純米大吟醸／大吟醸／純米吟醸

### Position 2：ワイン好き・日本酒初心者の入口（客層拡大・コンバージョン）
- 狙うクエリ：`ワイン好き 日本酒` / `白ワインのような 日本酒` / `低アルコール 日本酒` / `甘酸っぱい 日本酒` / `食前酒`
- フィルタ属性：ABV低め・酸味高め・微発泡・小容量・ギフト対応
- 主力商品：若水 純米吟醸生貯蔵（爽やか・炭酸割り）／純米にごり（甘酸っぱい・微発泡）／（将来）低アル新商品

### Position 3：話題・物語・ギフト（被引用フック・入口集客）
- 狙うクエリ：`音楽醸造 日本酒` / `珍しい 日本酒 ギフト` / `アマビエ 日本酒` / `話題の 日本酒`
- 主力商品：モーツァルトシリーズ／アマビエ／いなり（秦野萌酒）

### 足場：秦野・神奈川の地酒（ローカル王者）
- 狙うクエリ：`秦野 地酒` / `神奈川 日本酒 おすすめ` / `神奈川 燗酒`

## 3. A/B 判断（入口のクサビの実装）→ **推奨：ハイブリッド**
- **A：既存ラインの“見せ方”で取りにいく** → 即着手。若水・にごりで「ワイン的／甘酸っぱい」枠を今日から。
- **B：看板商品として新規開発** → 並行検討。旗艦＝「**低アル（≤10〜12%）× 高酸味 × ワイン層**」。1〜2年は主流化に間に合う開発リードタイム。
- **理由**：A で今すぐ信号を貯めつつ、B が“主流化の瞬間”に最も刺さる旗艦になる。猶予を最大活用。

## 4. 猶予期間でためる複利資産（バックログ・優先順）
1. **構造化データ**：storefront に schema.org `Product` / `FAQPage`（読まれた後の“引用されやすさ”）
2. **外部被引用の一致**：受賞DB／観光（秦野・丹沢）／レビューサイト／Googleビジネスプロフィール／媒体 — 水・音楽醸造・受賞を**全媒体で同じ事実**に揃える
3. **レビュー（Judge.me）** の UGC 蓄積
4. **ブログ知識記事**：「名水と酒造り」「音楽醸造とは」「ワイン好きへの日本酒」「燗の温度別ガイド」「秦野の地酒と地元料理ペアリング」
5. **（B採用なら）旗艦商品の仕込みを今期始動**
6. **事実の正確化**：水の受賞の出典確定（最優先の裏取り）
